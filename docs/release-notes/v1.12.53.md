## 修掉的不实描述

| 位置 | 原来写的 | 实际 |
| --- | --- | --- |
| `metadata.Get` | 无值时返回 nil slice 与 false | 返回 `(string, bool)`，没有 slice |
| `metadata.Pairs` | 暗示字符集校验与 `grpc-` 前缀保留 | 只做小写归一，不校验；重复键留最后一个值 |
| `encoding.GetCodec` | 返回新实例 | 返回同一个单例 |
| `encoding.Marshal` / `Unmarshal` | 「implements encoding.Codec」 | 包级函数，只服务头帧 |
| `driver.RoundTripper.RoundTrip` | payload 返回后可复用 | 只有 `bufsize=0` 成立，批量开启后被引用到 flush |
| `channel.Send` | 未提所有权 | 批量模式按引用排队，不拷贝 |
| `WithBufSize`（transport 与根包） | 未提所有权 | 补上同一条约束 |
| `WithCodec` / `WithServerCodec`（三处） | 头与消息体都用这个 codec | 只覆盖消息体，头帧固定内置 codec |
| `stream.recv` | 区分调用方 deadline 与读超时 | 两条分支都报 `Unavailable`，不区分 |
| `transport.WithServerTimeout` | 读起来像选项内部 clamp | 只存值，上限在 `Handle` 施加 |
| `DialContext` | 未说 dial 的超时来源 | 用 `defaultTimeout`，不受 `WithTimeout` 影响 |
| `balancer.PickInfo` | 「identifies the call」 | 两个字段当前仅信息性，`Authority` 已不在帧头 |
